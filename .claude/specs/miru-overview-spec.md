# Miru Overview Spec

## Status

Short reference only. Full Miru spec exists elsewhere.

## Product idea

Miru helps users understand emotional patterns from:

- journal entries
- structured check-ins
- wearable signals later
- user context
- feedback

## Core architecture

Inputs
→ Signal processing
→ Current emotional state
→ Pattern detection
→ Insights
→ Reflections
→ Recommendations
→ Feedback and trust update

## Core principle

Miru should not act like a generic chatbot.

Miru should produce traceable, personalized, safety-aware outputs.
