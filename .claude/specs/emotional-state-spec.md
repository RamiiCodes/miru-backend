# Emotional State Spec

## Status

IMPLEMENTED early version.

## Purpose

CurrentEmotionalState summarizes the user's recent emotional state.

## Current dimensions

- stress_level
- energy_level
- sleep_quality
- social_connection
- emotional_stability
- motivation
- self_esteem
- physical_activity
- eating_habits
- confidence

## Inputs

- structured check-ins
- journal-derived UserSignals
- future wearable signals
- future user context and feedback influences

## Rule

State calculation must remain explainable and testable.
